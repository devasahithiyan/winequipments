ISO 8573-1 is the international standard for compressed air purity. It grades air on three contaminants, always written in the same order: **particles : water : oil**. A specification of ISO 8573-1 [1:4:2] means particle class 1, humidity class 4 and oil class 2.

## The classes (ISO 8573-1:2010)

| Class | Particles 0.1–0.5 µm per m³ | 0.5–1 µm per m³ | 1–5 µm per m³ | Pressure dew point | Total oil mg/m³ |
| --- | --- | --- | --- | --- | --- |
| 0 | As specified, stricter than class 1 | | | As specified | As specified |
| 1 | ≤ 20,000 | ≤ 400 | ≤ 10 | ≤ −70 °C | ≤ 0.01 |
| 2 | ≤ 400,000 | ≤ 6,000 | ≤ 100 | ≤ −40 °C | ≤ 0.1 |
| 3 | not specified | ≤ 90,000 | ≤ 1,000 | ≤ −20 °C | ≤ 1 |
| 4 | not specified | not specified | ≤ 10,000 | ≤ +3 °C | ≤ 5 |
| 5 | not specified | not specified | ≤ 100,000 | ≤ +7 °C | – |
| 6 | | | | ≤ +10 °C | – |

Lower numbers are cleaner. Each contaminant is treated by different equipment, so the three classes are reached separately.

## Particles and oil: filters set those classes

Our WMF coalescing filters come in four colour-coded grades. Fitted in series, each protects the next.

| Grade | Particles | Oil carry-over | Classes reached |
| --- | --- | --- | --- |
| GP | 3 micron | – | Particle 3, oil 5 |
| ZP | 0.1 micron | 0.1 mg/m³ | Particle 1, oil 3 |
| ZO | 0.01 micron | 0.01 mg/m³ | Particle 1, oil 2 |
| ZC (activated carbon) | 0.01 micron | 0.005 mg/m³ | Particle 1, oil 1 |

Replace an element when its differential pressure reaches 0.7 bar g.

## Typical treatment trains

- **General plant air, class [–:4:–].** Compressor, receiver, GP pre-filter, refrigerated dryer.
- **Plant air with low oil, class [1:4:2].** Add a ZP and a ZO filter after the refrigerated dryer.
- **Very dry air, class [1:2:1].** GP and zero-oil filters, a molecular sieve desiccant dryer, then a dust after-filter and a ZC carbon filter.

Which class your process needs is set by your equipment makers, your customers or your industry standards. If you are unsure, send us the specification and we will propose the treatment train.

## Don't forget the condensate

Dryers and filters both collect condensate. An [automatic drain valve](/products/automatic-drain-valves.html) on each one keeps that water from being carried back into the air.
