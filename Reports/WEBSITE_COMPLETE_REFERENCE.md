## 3. Build pipeline (`build.py`)

1. Loads `site.json`, all product JSON, locations, articles (markdown parsed with a small custom `md()`), tools.
2. `render()` writes each page with Jinja and tracks which data files each page depends on (for `lastmod`).
3. Images: `picture()` creates AVIF/WebP/JPEG variants at several widths into `public/img` with cache in `.build-cache`; `studio()` cleans product cut-outs onto the "stage" look. Unused images are pruned (`pruned N unused images`).
4. CSS is bundled and minified into a content-hashed file (`css_ver`); JS is copied and minified with rjsmin; `js_ver` hash for cache busting.
5. SVG charts (dew point, saturation, cooling tower range/approach) are computed in Python (`dew_chart()`, `tower_chart()`), not drawn by hand.
6. Generates `sitemap.xml` (83 URLs, images, real last-modified dates), `sitemap.html`, `.htaccess` (from `htaccess.tpl` + redirects, including extensionless variants and `about`, `certifications`, `contactus`, `blog`, `downloads` -> `.html`), and `chat_knowledge.php` (catalogue facts for the chat assistant).
7. Output: 85 pages. Page families: home; about; certifications; contact (`contactus.html`); downloads; blog index + 25 articles; products index + 3 family pages (`compressed-air-treatment`, `process-cooling`, `cooling-towers`) + 20 product pages; industries index + 8 industry pages; locations index + 13 location pages; engineering-tools index + 3 calculators (air dryer sizing, chiller tonnage, cooling tower); sitemap page; 404; thank-you.

Commands: `python3 src/site/build.py`, then `/opt/homebrew/bin/python3 -m pytest -q`, preview with `python3 -m http.server 8080 -d public` (add `?static=1` for screenshots without motion).

## 4. Design system (summary; full detail in `DESIGN.md`)

- **Direction:** refined, light, industrial. Real photos and cut-outs only (no stock, no AI imagery). Facts are the design: no slot for numbers that are not real.
- **Colour tokens** (`tokens.css`): paper `#f6f7f3`, surface `#ffffff`, ink `#15201a`, ink-2 `#33403a`, muted `#56625b`, rules `#d3d9d4/#9aa59e`, brand green `#008810` (buttons), green-ink `#00700d` (text, AA), blue `#1d4e89` (charts/focus), hot `#b4432a` (chart points). Dark bands use ink with `#c9d3cc` text.
- **Type:** Archivo variable, self-hosted (`assets/fonts`), width-axis for character (display 70-74%, components 80-90%, body 100%), tabular numbers in tables; scale from 0.8125 rem labels to 5 rem hero.
- **Space and shape:** 4 px scale `--s-1..--s-20`, radii 8/12 px and pills, two light shadows, 44-48 px tap targets, container 76 rem, grids `minmax(0,1fr)`, no horizontal scroll 320-1440 px.
- **Layout:** sticky header with a Products mega menu (thumbnails, family counts, sizing tools); mobile action bar (Quote, WhatsApp, Call) appears after the hero; AI chat launcher above it.
- **Components:** buttons, product cards, readouts, spec explorer (mobile list, desktop table, finder), photo rail + lightbox, CSS-3D 360 chiller viewer, photo walk-around, computed SVG charts, FAQ details/summary, enquiry form, AI chat, calculators.
- **Motion:** CSS reveal on scroll (`[data-reveal]`, `--d` stagger), headline word raise (`[data-split]`), small hover lifts, ambient float, reading progress line; homepage adds Motion library (`home-motion.js`, loaded after idle). Everything off under `prefers-reduced-motion`; `.motion` class added only with JS.
- **Accessibility:** AA contrast, 3 px focus outline, one H1, ordered headings, alt text, keyboard support for tabs/360/lightbox.
- **Bundles:** `site.css` everywhere, `home.css` homepage, `viewer.css` pages with 360/walk-around.
- Recent UI work: cinematic homepage hero from real works photography and company film, need cards attached to hero, redesigned contact page, mobile footer/overflow fixes, page-to-page transitions.

## 5. Features

- **Quote/RFQ form** (`partials/enquiry.html` -> `send_rfq.php`): AJAX JSON or normal POST. Honeypot spam check, sanitising, optional file upload to `uploads/` (PHP execution blocked there by a generated `.htaccess`), emails to info@winequipments.com plus a secondary notification address configured in the PHP, logs leads to a server-side CSV (`leads_log_secure.csv`, blocked from download), redirects to `?form=success&ref=...` then the thank-you page. `thank-you.html` and `send_rfq.php` are disallowed in robots.txt.
- **AI chat** (`chat.js`, `api_chat.php`): Gemini models (`gemini-3.5-flash-lite`, fallback `gemini-3.5-flash`) grounded only in `chat_knowledge.php` (generated catalogue facts); never invents models or figures; recommends a model code with rated capacity and product link; per-IP rate limit 30 messages/10 minutes; falls back to a WhatsApp/phone message if the model is unavailable; CORS limited to winequipments.com and localhost. API key is in `secrets.php`, which lives **outside public_html** on the server (`/home/winequipments/secrets.php`) and is git-ignored. A local `secrets.php` placeholder exists in the repo folder. If the key expires, the chat falls back and the owner must supply a new Gemini key on the server.
- **Calculators** (`/engineering-tools/`): air dryer sizing (compressor CFM and four correction factors to a WRD/WHD model), chiller tonnage (LPM x temperature rise / 50.4 to TR and a WCP model), cooling tower (flow and temperatures to heat load, WCT model, water loss). Data comes from product spec tables via `tool_data()`.
- **Spec explorer**, photo rails, 360 chiller, photo walk-around, downloads page with 9 PDF catalogues (`/downloads/*.pdf`, originals from the company's catalogues).
- Site search: none. Language: English only.

## 8. SEO implementation (technical)

- **Per page:** unique `<title>` (<= 60 chars) and meta description (70-155), one H1, canonical to `https://winequipments.com/...`, Open Graph image, breadcrumbs.
- **Structured data (JSON-LD):** Organization+LocalBusiness (`#org`: address, geo/map, phones, founder, `sameAs`, `knowsAbout`, certification, areaServed India); BreadcrumbList; Product pages with `product_ld()` (no prices, no self-published ratings); FAQPage from each page's FAQs; family pages ItemList; location pages Service + OfferCatalog (ListItem) with `areaServed` City or Country; calculators WebPage; articles Article.
- **Internal linking:** articles list their products in frontmatter and link to product pages and tools; product pages list `related` products; location pages link to industry and tool pages; locations hub lists all landing pages.
- **Sitemap/robots:** `sitemap.xml` 83 URLs; robots allows all except thank-you, send_rfq.php, api_chat.php. `llms.txt` provides a factual summary for AI crawlers.
- **Redirects:** 34 old URLs (e.g. `/products/chiller.html` -> `/products/industrial-process-chillers.html`, `/catlogue/*.pdf`), extensionless variants, plus `/review`.
- **Performance:** PageSpeed mobile 97-99, desktop 100 (contact 96). AVIF/WebP, deferred JS, minified CSS/JS, immutable caching.
- **Tracking:** GA4 tag G-ETXTGY37TG loaded from `site.json`; the code sends `quote_submit` (site.js) and `whatsapp_click` (chat.js); `call_click` was planned but was not found in the JS, so check it before marking key events in GA4. Search Console property DNS-verified, sitemap submitted. Semrush Site Audit project exists (score 93% on 4 Oct before the latest fixes; ~120 product-schema "errors" from Semrush are awaiting an owner decision).
- **Tests (`tests/test_seo.py`):** title/description lengths, H1 count, canonical, JSON-LD parses, internal links resolve, `noindex` pages (404, thank-you), sitemap matches pages. They ignore iCloud conflict copies.

## 12. How to do common tasks

- **Add a product:** copy a similar `data/products/<slug>.json` (use `engineered: true` + `needs` if no datasheet), keep title <= 60 and description <= 155, add its photo to `photos.json` if wanted, link it from `related` of neighbours, build, test.
- **Add an article:** new `content/blog/<slug>.md` with frontmatter; link to existing product/tool URLs only.
- **Add a location/landing page:** append an entry to `locations.json` (use `scope:"country"` and `heading` for non-city pages; `tool` is optional); only state supply to confirmed cities.
- **Add a redirect:** append `[old, new]` to `redirects.json`; `.htaccess` regenerates.
- **Change a phone/address/company fact:** edit `site.json`, rebuild (catalogue PDFs are separate: `python3 src/site/catalogue/build_catalogues.py`).
- **Release:** build, run tests, commit source + `public/`, push `test`, owner deploys in cPanel, then verify live URLs (200) and the sitemap.
